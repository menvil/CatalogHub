## Реестр 1.2.0

Рекомендация — утвердить раздельные `GET /admin/central/categories/create` и `GET /admin/central/categories/{category}/edit`. Это повторяет CA-013. Числовой binding изолирует `create`, отсутствующий ID даёт 404. List и Detail направляют в каноническую форму. Старые Filament Create/Edit авторизуют переход и перенаправляют в канонические URL, которые сами требуют Category capability и Central mutation. Старые страницы не владеют формой. Успешная запись возвращает на Detail. См. [реестр 1.2.0](../planning/cataloghub-v2-screen-registry.md#changelog) и [маршруты CA-018](screens/CA-018-category-create-edit.md#retired-temporary-routes).

## Функциональная проверка

Feature-наборы Category Detail, Form, Slug Impact, Permissions и Category concurrency проверяют persisted facts, корневое и вложенное создание, изменение имени/slug, reparent, полный порядок, запрет циклов, устаревшие ревизии и preview, атомарный rollback, аудит, GET без изменений, права, канонические и legacy-маршруты. Browser-наборы проверяют переходы CA-016 → CA-017 → CA-018, работу без JavaScript, клавиатуру, сохранение введённого slug и responsive-состояния. Общий прогон включает Brands и компоненты. Миграции, модели, эталоны и пороги не менялись.

## Результаты проверок

Локально — `composer validate --strict`, Pint, PHPStan, 73 архитектурные проверки, `composer test`, SQLite database boundaries (551 passed, 11 skipped), Composer audit, JavaScript lint, 37 frontend-тестов, Vite build, npm audit, валидатор 18 контрактов, `git diff --check` и 20 целевых браузерных сценариев CA-017/CA-018 прошли. Оба аудита не выявили advisories. Канонический визуальный прогон и PostgreSQL/MariaDB выполнялись в GitHub Actions. Локальные пропуски SQLite учитываются отдельно от матрицы CI.

В GitHub Actions на коммите захвата прошли все 11 заданий, включая полный Playwright, визуальную регрессию и SQLite/PostgreSQL/MariaDB. Сравнения утверждённых экранов, включая Brands и CA-016, прошли. Последующее изменение ветки добавляет только этот отчёт и уточняет строку матрицы CA-018; для состава приложения и фикстур по-прежнему применимы снимки этого прогона.

# Deterministic UI fixtures

Visual fixtures are immutable presentation inputs, not demo data. Each fixture has a version marker, fixed locale `en-US`, timezone `UTC`, and a clock frozen at `2026-08-09T10:00:00Z` when it renders dates.

- Never use Faker, current time, remote images, unordered database queries, or generated avatars in a visual fixture.
- Use stable model keys and explicit ordering.
- A fixture change requires a screen-contract and visual-reference review; it does not update a baseline itself.
- `CentralShellFixture`, `SiteAdminShellFixture`, `PublicShellFixture`, and `AdminComponentGalleryFixture` are the Foundation fixture sources. New fixture pages must expose a version marker.
- `BrandListFixture` provides `brands-list-v3`: 24 explicit canonical Brands with all lifecycle states, nullable metadata, stable ordering inputs, and fixed UTC timestamps. Its final enrichment adds real persisted relations to eight representative Brands: six usable canonical global primary logos with deterministic square/wordmark proportions, one deliberately undeliverable canonical assignment, one missing-logo fallback, varied non-archived Product/category coverage, complete/partial/missing/outdated active-Locale translations, and an Apple Organization owner. It runs after the other Brand fixtures so KPI cards, identity states, translation reasons, Quality, and list counts are calculated from the same complete browser dataset; it is never production demo data.
- `BrandFormFixture` provides `brand-form-v5`: the fixed Active `Apple` record (ID `3`) with United States, 1976, official/support URLs, contact email, primary color, deterministic canonical logo, and the real `Apple Inc. / Organization #181100` ownership relation supplied by the shared Brand list enrichment. It also provides an unowned Draft Brand (ID `13016`) and `Apple Operations International` for the persisted assign/create/replace/clear journey. The previous Samsung form record remains as a non-primary continuity row so CA-011's locked aggregate fixture contracts do not change. All names, IDs, and timestamps are explicit; it is never production demo data.
- `BrandDetailFixture` provides `brand-detail-v9`: the fixed active Samsung record enriched with a usable global primary logo, Organization ownership, five editorial Tags, two ImportSource-backed external identities, eight realistically named non-archived Products across five derived Categories, deliberately varied recent timestamps, and fixed Brand timestamps. Support/contact is intentionally absent and `BrandTranslationFixture` adds four active-Locale outcomes—Approved, Human reviewed, Machine translated and Outdated—so Samsung derives exactly one Profile issue plus one Translation issue and 80% Quality. Archived Sony remains the separate fully populated, Organization-owned 100% Complete/no-issues state and Draft Zotac covers lifecycle/profile/logo repair. It creates no extra Brands, uses no remote data or fake view values, and is loaded only by the browser/visual harness; it is never production demo data.

# Deterministic UI fixtures

Visual fixtures are immutable presentation inputs, not demo data. Each fixture has a version marker, fixed locale `en-US`, timezone `UTC`, and a clock frozen at `2026-08-09T10:00:00Z` when it renders dates.

- Never use Faker, current time, remote images, unordered database queries, or generated avatars in a visual fixture.
- Use stable model keys and explicit ordering.
- A fixture change requires a screen-contract and visual-reference review; it does not update a baseline itself.
- `CentralShellFixture`, `SiteAdminShellFixture`, `PublicShellFixture`, and `AdminComponentGalleryFixture` are the Foundation fixture sources. New fixture pages must expose a version marker.
- `BrandListFixture` provides `brands-list-v2`: 24 explicit canonical Brands with all lifecycle states, nullable metadata, stable ordering inputs, and fixed UTC timestamps. Its final enrichment adds real persisted relations to eight representative Brands: six canonical global primary logos, varied non-archived Product/category coverage, complete/partial/missing/outdated active-Locale translations, and an Apple Organization owner. It runs after the other Brand fixtures so summary cards and list rows are calculated from the same complete browser dataset; it is never production demo data.
- `BrandFormFixture` provides `brand-form-v4`: the fixed Draft `Samsung Form Fixture` (ID `13013`) with South Korea, 1938, official/support URLs, contact email, `#1428A0`, fixed timestamps, deterministic local logo, and a real persisted Organization ownership relation. It also provides an unowned Draft Brand (ID `13016`) and a second existing Organization for the persisted assign/create/replace/clear journey. All names, IDs, and timestamps are explicit; the browser harness loads the fixture after `BrandListFixture`, and it is never production demo data.
- `BrandDetailFixture` provides `brand-detail-v2`: the fixed active Samsung list record enriched with the Phase 10 canonical profile and three explicit canonical Product references, plus the existing archived Sony and Draft Zotac list records for state/lifecycle coverage. It creates no extra Brands, uses no Faker, and is loaded only by the browser/visual harness after the list/form fixtures; it is never production demo data.
